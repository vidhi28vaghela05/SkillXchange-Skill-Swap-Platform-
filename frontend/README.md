# SkillXchange Frontend

Simple Skill Swap Platform Frontend.

## Tech Stack
- React (Vite)
- Tailwind CSS
- Framer Motion
- Axios
- Lucide React (Icons)

## Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev`

## Features
- Auth (Login/Register)
- Profile management (Skills offered/wanted)
- Matching algorithm (Mutual skill exchange)
- Swap request system (Sent/Received)
